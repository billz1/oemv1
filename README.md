# OEM Supplier AI Research - Static Vercel JSON Fix

Pure static app. No npm, no backend, no Python.

Deploy on Vercel with:
- Framework: Other
- Install command: echo no-install
- Build command: echo no-build
- Output directory: .

Files required only:
- index.html
- styles.css
- app.js
- vercel.json

Do not include package.json, src/, api/, requirements.txt, or vite config.
